# 📒 CodeNotes (ASP.NET MVC)

Веб-приложение для создания, хранения и управления заметками, разработанное на ASP.NET MVC с использованием SQL базы данных и работы с данными без Entity Framework.

---

## 🚀 Возможности

- Создание заметок  
- Просмотр списка заметок  
- Просмотр детальной информации о заметке  
- Редактирование заметок  
- Удаление заметок  
- Хранение данных в SQL базе данных  

---

## 🛠 Технологии

- ASP.NET MVC  
- C#  
- SQL Server  
- ADO.NET / ручные SQL-запросы  
- HTML / CSS  
- Razor Views  

---

## 🏗 Архитектура проекта

Проект построен по MVC-паттерну:

- **Models** — описание структуры данных  
- **Views** — Razor представления (UI)  
- **Controllers** — обработка логики и маршрутизация  
- **Data Access Layer** — работа с SQL через запросы  

---

## 📦 Основная сущность (Note)

Заметка содержит:

- Id  
- Title (заголовок)  
- Content (содержимое)  
- CreatedAt (дата создания)  

---

## 🧩 Функциональность (CRUD)

Реализованы базовые операции:

- Create — создание заметки  
- Read — просмотр заметок  
- Update — редактирование заметки  
- Delete — удаление заметки  

---

## 🗄 Работа с базой данных

- Используется SQL Server  
- Доступ к данным реализован через SQL-запросы  
- Без использования ORM (Entity Framework не применяется)  
- Подключение через connection string

## ▶️ Запуск проекта

### 1. Клонирование репозитория

git clone https://github.com/Andrey-Strekalov/ASP.NET_CodeNotes.git

- Открыть `.sln` файл
